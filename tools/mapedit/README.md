# MapEdit

macOS 用のゲームプレイ配置エディタです。Xcode または Command Line Tools が使える環境で、Finder でこのフォルダの `run.command` をダブルクリックして起動します。ターミナルから起動する場合は、リポジトリのルートで次を実行します。

```sh
./tools/mapedit/run.sh
```

1. Godot で `scenes/stages/time_attack.tscn` または `scenes/stages/theater_stage.tscn` を直接開きます。**プロジェクト → ツール → MapEdit: Copy gameplay placements** を実行します。項目が出ない場合は、プロジェクト設定のプラグイン一覧で **MapEdit** を有効にします。
2. MapEdit に切り替えて **⌘V**。上部の「配置」でタイルの種別または既存マーカーを選びます。左ドラッグで配置・移動、右ドラッグで選択種別のタイルを消去します。
3. **⌘C** で編集結果をコピーし、Godot の **プロジェクト → ツール → MapEdit: Paste gameplay placements** を実行します。件数を確認して反映した後、Godot でシーンを保存します。
4. 続けて編集するときは、反映後の Godot シーンから改めてコピーします。Godot の配置が取り込み時点から変わっていると貼り付けは止まります。

| 操作 | 入力 |
| --- | --- |
| 元に戻す / やり直す | ⌘Z / ⌘⇧Z |
| パン | Space + 左ドラッグ、中ボタンドラッグ、トラックパッドの二本指スクロール |
| ズーム | マウスホイール、ピンチ、⌘ + トラックパッドスクロール |
| 全体表示 | ⌘0 |
| 作業 JSON を開く / 保存 | ⌘O / ⌘S |

キャンバスは配置を色と ID で表示します。装飾は Godot で編集します。ゲームシーン内のマーカーは位置のみ編集できます。パレットはゲームプレイ用の既定アトラスタイル、取り込んだ既存タイル、登録済みのシーンタイルを含みます。
