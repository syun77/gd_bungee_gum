# MapEdit

macOS 用のゲームプレイ配置エディタです。Xcode または Command Line Tools が使える環境で、Finder でこのフォルダの `run.command` をダブルクリックして起動します。ターミナルから起動する場合は、リポジトリのルートで次を実行します。

```sh
./tools/mapedit/run.sh
```

1. Godot で `scenes/stages/time_attack.tscn` または `scenes/stages/theater_stage.tscn` を直接開きます。**プロジェクト → ツール → MapEdit: Copy gameplay placements** を実行します。項目が出ない場合は、プロジェクト設定のプラグイン一覧で **MapEdit** を有効にします。
2. MapEdit に切り替えて **⌘V**。右ペインの「配置種別」グリッドでタイルの種別または既存マーカーをクリックします。タイルのバリエーションは下の「タイル」欄で選びます。左ドラッグで配置・移動、右ドラッグで選択種別のタイルを消去します。
3. 対象ステージを Godot で開いたまま、右ペインの **Godot に送る** を押します。Godot に出る差分の確認画面で反映し、シーンを保存します。
4. 直接送信で反映した後は、その送信内容が次の比較基準になります。引き続き MapEdit で編集して送信できます。Godot の配置が取り込み時点から変わっていても、取り込み元の配置が記録されていれば、双方の変更を比較して重ならない編集の差分を表示します。同じセルやマーカーが双方で異なる値に変更されている場合は、その場所を表示して反映を止めます。追加できるチェックポイントがある場合は、Godot の現在の配置を保ってチェックポイントだけ追加する確認が出ます。

| 操作 | 入力 |
| --- | --- |
| 元に戻す / やり直す | ⌘Z / ⌘⇧Z |
| パン | Space + 左ドラッグ、中ボタンドラッグ、トラックパッドの二本指スクロール |
| ズーム | マウスホイール、ピンチ、⌘ + トラックパッドスクロール |
| 全体表示 | ⌘0 |
| 表示位置の移動 | 下部のミニマップをクリックまたは左ドラッグ |
| 作業 JSON を開く / 保存 | ⌘O / ⌘S |

ウィンドウを閉じるか ⌘Q で終了すると、現在の配置、ズーム倍率、スクロール位置を作業セッションに自動保存し、次回起動時に復元します。Godot への反映は手順 3 で行います。

キャンバスは配置を色と ID で表示します。装飾は Godot で編集します。右ペインの「チェックポイント」を選ぶと、左クリック・ドラッグで複数配置でき、右クリック・ドラッグで削除できます。足元は選んだセルの下辺に揃います。既存のチェックポイントを移すときは、足元のすぐ上のセルで削除して配置し直します。その他のマーカーは位置を編集できます。パレットはゲームプレイ用の既定アトラスタイル、取り込んだ既存タイル、登録済みのシーンタイルを含みます。

## 直接貼り付けのログ

MapEdit の起動元のターミナルと、Godot エディター下部の「出力」で `[MapEditPaste]` を探します。同じ送信内容は両側で同じ 12 桁の識別子になります。接続前や受信途中の行は `[-]` と表示します。

- Godot の `listen …: OK` は待ち受け開始です。`Already in use` が出た場合は、別の Godot ウィンドウが待ち受けていないか確認します。
- `request received` の後に `validation rejected` が出た場合は、その行に貼り付けを拒否した理由が表示されます。
- `preview opened` は差分の確認待ちです。直接送信の応答は反映またはキャンセル後に返ります。`changes applied to editor scene` はエディターに反映済みで、シーンは Godot で保存します。

## 食べ物の配置

右ペインで **食べ物** を選び、**料理の種類** から料理名を選択します。左クリック・ドラッグで配置し、右クリック・ドラッグで消去します。レストランと Time Attack の両方で使えます。食べ物の欄がない既存セッションでは、Godot からステージをコピーし直してください。

**フランスパン** と **音符** も右ペインに別々の配置種別として表示されます。選択した種別だけを配置・消去します。既存の作業セッションに項目がない場合は、Godot から対象ステージをコピーし直します。

## 可動ブロック

右ペインの **可動ブロック** を選ぶと、バンジーガムで引っ張れる軽いブロックを左クリック・ドラッグで配置できます。右クリック・ドラッグで消去します。レストランと Time Attack で使えます。

## 即死トゲ

右ペインの **即死トゲ** を選び、左クリック・ドラッグで配置、右クリック・ドラッグで消去できます。レストランと Time Attack で使用でき、プレイヤーが触れると死亡します。項目が表示されない既存セッションは、Godot からステージをコピーし直します。

## タイル設定

右ペインで配置種別を選び、**タイル設定…** を開くと、表示名・色・ショートカットを変更できます。変更はその場で反映・保存されます。ショートカットには英数字1キーを割り当て、キャンバス上で押すと種別を切り替えます。空欄で解除でき、同じキーを複数の種別には割り当てられません。「既定に戻す」で編集中の種別だけを初期設定に戻します。設定は MapEdit に保存され、次回起動時や別ステージでも使われます。

## 破壊可能ブロックの配置

MapEditを再起動し、Godotからステージをコピーし直すと、配置種別に「破壊可能ブロック」が表示される。「茶色レンガ」を選び、通常の左クリック・ドラッグで配置、右クリックで消去する。Undo/Redo・保存・Godot反映は共通操作。項目はTerrainTilesのソース4/(0,0)を選ぶ専用ブラシで、保存先と衝突生成は既存の地形と共通。ゲーム内ではバンジーガムの先端が命中するとその1マスが壊れ、ガムが戻る。再スタート時に配置を復元する。

## 配置種別の縁取り

配置種別を選び「タイル設定」を開くと、「縁取りを有効にする」と「縁取りの色」を設定できる。初期状態は無効。「既定に戻す」でも無効になる。有効時は配置済みタイル・配置プレビュー・ミニマップに内側の縁取りを表示する。幅は画面上2pxを基本とし、小さなセルでは塗りを残すよう縮める。マーカーにも適用する。設定は配置種別ごとに自動保存し、表示名・塗り色・ショートカットの変更では保持する。ゲーム内画像やマップの配置データは変更しない。

## 一方通行床の配置

レストランと Time Attack の両方で「一方通行床」を選択し、タイル欄から「左端・中間・右端・単独」を選べる。左クリック・ドラッグで配置、右クリック・ドラッグで消去し、共通の Undo/Redo・保存・Godot への送信を使う。下から通過し、上から着地する床として専用の OneWayPlatforms レイヤーに保存する。古い作業セッションに項目がない場合は、Godot で保存済みステージを開き直してコピーし、MapEdit に貼り付ける。

一方通行床はマップ・配置プレビュー・ミニマップともセル上端に幅いっぱい、高さ1/5の帯で表示する。薄い帯に収まらないタイルIDは表示しない。配置・消去の操作単位は従来どおりセル全体。

コピー・送信では現在開いているステージの必須ノード名を検証する。`TerrainTiles`（地形）、`Terrain`、`Checkpoints`、`PlacementMarkers/PlayerSpawn`、`PlacementMarkers/Exit` の名前を維持する。必須ノードがない場合は、その名前をエラーに表示する。レイヤーには32×32のTileSetが必要。
