# バンジーガム操作試作

静的地形の角への巻き付きは [gum-wrapping.md](gum-wrapping.md) を参照。

操作詳細は `keyboard-controls.md` を参照。F5で既存レストランマップを起動する。

## 操作と実装範囲

|入力|動作|
|---|---|
|左右矢印／A,D|左右移動。X照準中は移動を抑制|
|Z|接着を切断し、接触面から短く蹴り出す。コヨーテタイム外の空中では切断のみ|
|X長押し＋方向キー|未接着時、8方向の照準。キーを離しても方向を保持|
|照準中にXを離す|射程いっぱいのレイを発射。接着直後から自動収縮|
|接着中に下を保持|弛緩へ移り自然長を延長|
|弛緩中に上を保持|自然長を手動短縮。解放で保持|
|接着中にXを押す|弛緩から自動収縮へ。収縮中は変化なし|
|R|接続を破棄してステージ全体と箱を再生成|

同時接続は1本。入口のミント色の箱は軽量（0.4）、コーラル色は重量（6）。プレイヤーの計算質量は1。区画3・4の配置マーカーにも同じ箱を配置する。両者ともRigidBody2Dであり、重い箱も固定物ではない。敵・投射物・出口・区画チェックポイントは未実装。マップ全体をガムで攻略できるかの受け入れ検証は未完了。

## 力学と安全条件

`game_settings.gd` のResourceを `resources/game_settings.tres` としてGameのSettingsに割り当て、PlayerとGumで共有する。初期値はばね係数35、減衰9、収縮180 px/s、自然長下限36 px、射程attachment_range 400 px／最大接続長maximum_length 400 px（独立設定）、最大張力2800、手動延長180 px/s・短縮90 px/s、手動延長上限は最大長−240 px。下限より近くに接着した場合、収縮で自然長を伸ばさない。

物理起点はプレイヤーの足元から(0,-34)。レイは自分を除外し、地形レイヤー1と物体レイヤー4を調べる。StaticBody2DとRigidBody2Dへ接着でき、`gum_blocked` グループの対象には接着できない。最初の面が不適格でも奥の対象へは貫通しない。

接着点は対象のローカル座標で保持し、移動・回転へ追従する。接着時の距離を自然長とし、自動収縮を開始する。下入力で弛緩へ移り、上下保持で自然長を連続調整、解放で長さを固定する。詳細な入力解放待ち・上限規則はkeyboard-controls.mdに従う。自然長以下では減衰も含め力をゼロにする。伸びた場合だけ `clamp(k * extension + c * separation_speed, 0, maximum_tension)` の張力を計算。張力の伸びと減衰は総経路長とその解析的変化速度を使う。対象の速度は回転による接着点速度も含む。プレイヤーへF/m×deltaを積分し、剛体へ隣接する支点方向の同じ大きさのFを世界向きのオフセットで `apply_force` する。解除は接続情報のみを破棄する。

静的地形への交差は外周の凸角へ巻き付き、角への支持が不要になると支点を外す。最大長900 pxは総経路長に適用する。対象削除、経路長超過、経路生成不能・予算超過、未対応の動的障害物との交差は理由を表示して安全解除する。支点反力を含む系全体で作用反作用を維持する。

Gameが接続検証→Z/Xジェスチャー入力→張力→プレイヤー衝突移動→描画の順で1回ずつ更新する。剛体の積分・重力・衝突はエンジンに任せる。箱の重力は標準980×1.122449でプレイヤーの1100に近づける。プレイヤーと箱の通常接触では追加の押す力を実装しない。

## 表示

ガムはピンクの線と接着点で表示。弛みは下へたわむ曲線、張力は太さと赤み、およびHUDの百分率で示す。HUDは収縮／緩めの選択モード、総経路長・自然長・支点数・最大長に対する比率・解除理由も表示する。線のたわみは物理に使わない。描画起点は動作ごとの手先座標であり、物理起点をアニメーションで移動させない。

発射アニメーションはX解放時の即時レイ判定と同時に再生する。張力のある空中では接着方向・速度に応じて牽引／ぶら下がりを再生する。全身を照準へ回転させず、左右反転で対応する。解除後は通常の待機・走り・空中表示へ戻る。

## 検証

`Godot --headless --path gd-bungee-gum --log-file /tmp/gum-check.log --script res://tools/verify_gum.gd`

静的／動的レイ、巻き付きと不適格対象、弛み、収縮と長さ保持、解除時の速度保持、最大長、回転接着点と点速度、等大逆向きの力、軽重の実剛体応答、対象削除、180ティックの振り子、実Gameでの天井収縮・発射／牽引表示・解除入力を確認する。既存プレイヤーとマップの検証も併用する。Z/X/上下の物理キー入力・照準・手動長さ調整・収縮開始・キャンセルは `verify_controls.gd` で確認する。実機の操作感・全区画攻略・描画fps別比較・高速投射物は追加検証対象。

床離脱後は`coyote_time`（初期値0.10秒、0で無効）の間、一度だけ接地キックを受け付ける。成功したキックは猶予を消費する。詳細は[キーボード操作](keyboard-controls.md)を参照。
