# バンジーガム能力分析

## 目的

本資料は『HUNTER×HUNTER』の念能力「伸縮自在の愛（バンジーガム）」を、ゲーム設計へ落とし込むために構造化した分析である。原作・アニメ設定として確認できる事実と、本プロジェクト向けの設計解釈を分けて扱う。

## 設定として確認できる中核

バンジーガムは、ヒソカが自分のオーラを変化させ、ガムの粘着性とゴムの伸縮性を同時に持たせる念能力である。よく伸び、素早く縮み、さまざまな対象へ貼り付けられ、使用者の意思で剥がせる。念の六系統では、オーラの性質を変える「変化系」に位置付けられる。

したがって、能力を構成する最小要素は次の5つである。

1. **生成**: 使用者のオーラから弾性と粘着性を持つ接続を作る。
2. **接着**: 自分、相手、地形、物体を接続端点にできる。
3. **伸長**: 端点間の距離が広がることを許容し、張力を蓄える。
4. **収縮**: 蓄えた張力を、引き寄せ・加速・反射へ変換する。
5. **解除**: 使用者が意図したタイミングで接着を剥がし、拘束や張力を解放する。

出典: [日本テレビ『HUNTER×HUNTER』用語解説](https://www.ntv.co.jp/hunterhunter/dictionary/)

## 能力の本質

### 直接攻撃ではなく関係性を操作する能力

バンジーガムそのものは、炎や刃のように接触だけで大ダメージを与える能力ではない。二つの端点をつなぎ、その間に生じる距離、方向、張力、解除タイミングを操作することで、既存の力を有利な結果へ変える能力である。

このため強さは単純な威力ではなく、以下の掛け合わせで決まる。

- 何と何を接続したか
- 接続を相手が認識しているか
- どの方向へ、どれだけ引き伸ばしたか
- いつ収縮または解除するか
- 地形、物体、敵の攻撃をどう再利用するか

### 「ガム」と「ゴム」は別々の機能ではない

粘着性は端点を固定し、伸縮性は端点間へ力を伝える。この二つが同時に働くため、単なるロープ、グラップリングフック、スプリング、接着剤のいずれとも異なる。

基本構造は常に次の循環になる。

> 接着する → 距離を作る → 張力を蓄える → 収縮または解除する → 結果を利用する

この循環が、ゲームにおける中心操作として最も自然である。

## 代表的な応用の分類

### 移動

- 地形へ接着して自分を引き寄せる。
- 振り子運動で移動方向を変える。
- 伸ばした接続を縮め、瞬間的な加速を得る。
- 地面や壁へ固定し、吹き飛ばしに耐える。

### 敵の制御

- 敵を自分、地形、別の物体へ接続する。
- 接続後に引き寄せ、間合いを強制する。
- 手足や武器の軌道を乱す。
- 敵自身の移動や攻撃で張力を蓄えさせ、行動を裏目に出す。

### 攻防の変換

- 飛来物を受け止め、弾性で返す。
- 武器や物体を加速して射出する。
- 衝撃を吸収し、別方向へ解放する。
- 攻撃を避けるだけでなく、攻撃の運動量を次の行動資源へ変える。

### 罠と心理戦

- 見えにくい接続や複数の端点を事前に配置する。
- 相手に自由に動けると思わせ、張力が生じた後で拘束を顕在化させる。
- 収縮と解除のタイミングを遅らせ、相手の予測を外す。
- 同じ接続状態から複数の結果を選べるため、相手に読み合いを強制する。

## 強み

- **少数の一貫したルールから用途が増える**: 状況依存の専用技を大量に必要としない。
- **地形と物理現象を遊びへ変えられる**: ステージ上の配置そのものが戦術資源になる。
- **攻撃・防御・移動を分断しない**: 一つの接続が複数の役割へ遷移する。
- **準備と即興の両方を許容する**: 罠の設置にも、攻撃への瞬間的な返しにも使える。
- **プレイヤースキルが結果へ現れやすい**: 照準、端点選択、張力管理、解除タイミングに習熟余地がある。
- **相手の力を利用できる**: 強い攻撃ほど大きな反撃機会にもなり得る。

## 弱みと成立条件

以下は能力の性質から導ける設計上の弱点であり、必ずしも原作内で数値化された制約ではない。

- 接続先がなければ能力の価値が下がる。
- 張力は接続した双方へ作用するため、使用者自身も位置や姿勢を崩され得る。
- 接着前、または十分な張力がない状態では即効性が低い。
- 多数の接続を同時管理すると、プレイヤーの認知負荷が急増する。
- 強力な結果には距離、相手の運動量、事前配置などの準備が必要になる。
- 接続状態が完全に不可視・無制限・無コストだと、相手側の対処可能性が失われる。
- 能力単体の自動追尾や自動攻撃を強くしすぎると、創意工夫より能力値が支配的になる。

## ゲーム化における設計原則

### 1. 主役は「技一覧」ではなく接続システム

パンチ、拘束、ダッシュなどを独立した魔法として実装するのではなく、同じ接続・張力モデルから結果が生まれる設計を優先する。プレイヤーがシステムを理解して新しい使い方を発見できることが、バンジーガムらしさになる。

### 2. 基本操作は Attach / Tension / Release

- **Attach**: 接続先を選ぶ。
- **Tension**: 自分または対象の運動で張力を作る。
- **Release**: 収縮させるか、剥がすかを適切な瞬間に選ぶ。

この3段階を、移動・戦闘・パズルで共通利用する。

### 3. 張力を明確なゲーム状態にする

張力は単なる内部物理値ではなく、プレイヤーが判断できる情報として提示する必要がある。線の太さ、色、振動、音程、パーティクルなどを組み合わせ、方向と蓄積量と破綻リスクを読めるようにする。

### 4. 接続には相互作用を持たせる

接続は一方的なスタンではなく、双方に影響する状態とする。軽い対象は自分へ飛び、重い対象へつなぐと自分が引かれる。敵の力が強ければ制御が難しくなる一方、その力を反射に使える。この相互性が判断とリスクを生む。

### 5. 環境を能力の一部として設計する

壁、天井、柱、可動物、壊れる物、敵、飛び道具を接続候補として配置する。平坦で接続先の少ない空間ばかりでは、能力の表現力が失われる。

### 6. 強さを数値より選択肢に置く

単純なダメージ倍率を成長の中心にせず、同時接続数、接続可能な対象、収縮制御、張力保持、空中での解除精度など、操作上の選択肢を広げる成長が適している。

### 7. 失敗にも物理的な結果を与える

狙いを外す、張力を読み違える、解除が早いといった失敗を単なる不発にせず、意図しない方向への移動、敵への接近、物体の誤射などの結果へつなげる。予測可能な失敗は習熟の教材になる。

## 本プロジェクトで守るべき能力の核

横視点のステージクリア型2D物理アクションとして、次の要件をテーマの同一性を保つための核とする。

1. 粘着と伸縮が同一の接続に共存する。
2. 少なくとも自分・敵・地形・物体の複数カテゴリを接続できる。
3. 距離によって張力が生まれ、収縮によって力へ変換される。
4. プレイヤーが接着または解除のタイミングへ介入できる。
5. 移動、攻撃、防御、拘束のうち複数を共通システムで実現する。
6. 地形と相手の運動を利用する余地がある。
7. 正解技を選ぶだけでなく、接続関係を考える余地がある。

これらを成立させるため、物理エンジンによるシミュレーションを必須基盤とする。接続状態と能力ルールはゲーム側で管理し、質量、速度、外力、衝突、重力が組み合わさった運動結果を物理エンジンに解かせる。詳細は[物理シミュレーション基盤方針](physics-foundation.md)を参照する。

## 現時点で確定しない事項

以下はゲーム仕様を決める段階で選択すべきであり、この分析では確定しない。

- 一度に維持できる接続数
- 射程、耐久力、最大張力、消費リソース
- 敵が接続を解除する方法
- 原作キャラクターを直接扱うか、能力の着想だけを独自世界観へ用いるか

本作は横視点のステージクリア型2D物理アクションとし、複数区画からなるステージでパズル、移動、戦闘を同じ物理ルールから構成する。詳細は[ゲーム基本方針](game-direction.md)を参照する。

## 結論

バンジーガムの魅力は、「貼り付く」「伸びる」「縮む」「剥がす」という理解しやすい物性を、使用者の判断によって移動・拘束・防御・反射・罠へ変換できる点にある。

ゲームとして目指すべきなのは、原作の個別場面を必殺技として再現することではない。接続と張力の一貫したシステムを提供し、プレイヤー自身が状況から応用を発見できる状態である。端的に言えば、バンジーガムは「ゴム紐を撃つ能力」ではなく、**二つの対象の関係を一時的に作り替え、蓄えた力を好きな瞬間に意味へ変える能力**である。
