# バンジーガムの飛行・回収仕様

実装済みの飛行・回収の基準仕様。入力は [keyboard-controls.md](keyboard-controls.md)、接着後の物理規則は [gum-wrapping.md](gum-wrapping.md) に従う。

## 狙い

X押下で先端が高速に伸び、面へ到達して接着し、それから自動収縮が始まる。Zで外した線は手元へ回収される。回収を待たず、新しいX押下で回収を中断し即再発射できる。発射・回収の見た目と、接着後のばね・作用反作用・運動量を区別する。

## 状態と操作

接続の状態を READY / OUTBOUND / ATTACHED / RETURNING とし、接着中だけ CONTRACT / LOOSEN を持つ。Gameは方向キーと押下エッジを読み、独立した照準ジェスチャー状態は持たない。

|状態|Xを新しく押す|Xを離す|Zを押す|
|---|---|---|---|
|READY|OUTBOUNDへ即発射|何もしない|既存のキック判定|
|OUTBOUND|無効、解放まで消費|何もしない|飛行中止、RETURNINGへ＋キック判定|
|ATTACHED|既存の自動収縮操作、解放まで消費|何もしない|即時物理解除、RETURNINGへ＋真上ジャンプ|
|RETURNING|回収表示を即時キャンセルし再発射|何もしない|回収を継続＋キック判定|

Rは最優先で全状態・表示を破棄して再開する。ZとXが同時ならZ優先。Xは押下エッジだけを処理し、保持・解放は発射に使わない。回収完了や接続喪失で保持済みXを再発射へ読み替えない。

通常移動、重力、衝突は全状態で継続し、方向指定でも移動を抑制しない。上下による長さ調整はATTACHED限定。接着前から保持していた上下キーは、飛行中に押し始めたものを含め、各キーを離すまで接着後の長さ調整に使わない。

## 発射と飛行判定

- X押下時の物理原点と正規化した照準方向を固定し、先端をワールド空間で直進させる。ホーミング、重力、プレイヤー速度の加算は行わない。プレイヤー側の根元は移動に追従する。
- 初期値は `gum_shot_speed = 2400 px/s`。400 pxで約0.167秒、60 Hzで約10ティック。距離に比例した時間とし、至近距離に演出のための最低待ち時間を加えない。
- 射程は発射点からの先端の累積移動距離 `attachment_range`。別途、現在の物理原点から先端までの長さが `maximum_length` を超える場合も飛行を終了し回収する。射程と接続長上限は独立した設定を維持する。
- 各固定更新で前回先端から今回先端までの区間レイを取り、最初に衝突した面で停止する。プレイヤーを除外し、地形・動的物体を現行レイヤーで検出する。薄い壁を飛び越えず、接着禁止面を貫通して奥へ接着しない。
- 照準レイは命中予告のみ。発射時点の命中相手・位置を予約しない。移動物体は到達ティックの実際の物理空間で判定する。ティック間を横切る高速物体の連続衝突検出は初期対象外とし、必要なら相対スイープへ拡張する。
- 接着候補では現行の接着可否に加え、移動した根元から命中点までの初期経路が遮られていないことを検証する。飛行中に障害物へ線を引き回した状態から、後付けで接着・巻き付きは作らない。経路が塞がれた飛行は回収へ移る。接着後の静的角への巻き付きは従来どおり。
- 有効な面に到達したら相手のローカル座標で接着点を記録し、経路長を自然長に設定、CONTRACTへ入る。接着成立ティックは自然長を縮めず張力ゼロ、次の固定更新から通常の収縮・ばね計算を行う。発射ポーズの終了は待たない。
- 射程末端での命中は判定してから空振り扱いにする。無命中・禁止面・長さ超過・無効経路は先端位置からRETURNINGへ。飛行中は張力も両端へのガム力もゼロ。

輪っかの拡大判定への命中では、到着時に先端と接着位置をそのタイル中央へ揃える。自然長・経路・最大接続長の判定も中央を基準とする。地形・箱では実命中位置を使う。詳細は [gum-anchor-tile.md](gum-anchor-tile.md)。

## 物理解除と回収表示

Zはキックの成否にかかわらず接続を即時解除し、そのティックのガム力を適用しない。Gumの解除自体は両端の速度を保持する。Playerは接着中のZで下向き外部速度を打ち消して真上へkick_speedを加算し、上向き・水平速度は保持する。未接着の接触／コヨーテキックは既存の規則に従う。回収は物理接続を持たない表示アニメーションで、物体を引き続けたり、プレイヤーを引き戻したりしない。

解除直前のワールド座標の表示折れ線（先端・巻き付き支点を含む）を保存する。先端側から経路長を毎秒 `gum_return_speed` ずつ削り、先端が支点を逆順に通って手元へ戻る。初期値は3200 px/sで、400 pxなら約0.125秒。支点と解除点は対象物から切り離し、動的物体へ追従しない。根元だけ現在の手元に追従する。回収のために新しい支点や物理衝突を生成しない。

プレイヤーの高速移動で末端区間が伸び続けても表示が残留しないよう、`gum_return_max_duration = 0.25 s` で終了する。これは表示寿命だけを制限し、速度には影響しない。回収中の新規X押下は同じティックに残りの折れ線・先端を破棄して即再発射する。一つの先端だけを表示し、古い回収と次の発射を重ねない。

安全解除（相手消失・長さ超過・経路失敗）も最後に有効だった表示から回収する。無効な対象へ座標問い合わせしない。再開・シーン終了は回収を再生せず即時消去する。すでに回収中のZは回収を最初からやり直さない。

## 表示・実装方針

飛行・回収は現在のピンク系の線、先端、グローを共用し、張力による赤色・太さ増加は適用しない。接着時から既存の張力表示へ移る。発射ポーズは発射時に開始し、飛行中の基本姿勢とする。接着したら収縮／懸垂の既存姿勢判定へ移る。回収専用のキャラクタースプライトは必須にせず、ジャンプ・落下の姿勢を優先する。「戻るアニメーション」はガムの線と先端の回収を指す。

HUDはFLYING / RETURNINGを表示し、張力・自然長は接着中のみ表示する。命中予告はREADY時のみ表示し、発射から回収完了までは非表示。方向入力にかかわらず常に薄く表示する。X保持による照準ズームはなく、飛行・回収の長さを接着経路長ズームへ流用しない。

Gameが方向と押下入力、Gumが飛行／接続／回収状態を所有する。固定更新は入力とキャンセル→先端移動・接着判定／既存接続計算→Player.simulate→表示。接着した更新では力を計算しない分岐を明示する。物理原点と描画用手元の既存の差は維持し、描画オフセットで命中点を変えない。共有Settingsに速度・回収寿命を追加し、照準レイと先端スイープは判定区間だけを分け、接着可否を共用する。

## 検証

1. 近距離・400 px・斜め方向で距離／速度に従って飛び、到達前は未接着・張力ゼロ。30/60/120 Hzで飛行時間が1ティック以内の誤差に収まる。
2. 薄い壁・手前の禁止面を貫通しない。発射後に動いた箱は到達時の位置で判定し、照準時の空間へ接着しない。
3. 飛行中のプレイヤー移動、経路遮断、射程端の命中、射程と最大長の大小関係、対象消失を検証する。
4. 接着成立更新は自然長＝実経路長・張力ゼロ、次更新から収縮する。相互力、動的物体の質量差、接着点追従、角巻き付きは既存回帰を維持する。
5. 地上／空中／コヨーテのZで即時解除し、回収中の力ゼロと接着ジャンプ（下降打ち消し／上昇加算／水平保持）を確認する。飛行中Z、回収中Zも検証する。
6. 巻き付いた線の逆順回収、動的物体解除後の非追従、最大回収時間、再開時消去を確認する。
7. 回収中X押下で即時消去・同更新で再発射。X解放は何もしない。同時Z/X、保持済みX、飛行中Xの解放、上下解放待ちで誤発射・誤調整が起きない。
8. 実機で先端の速度感、至近距離の読みやすさ、空振りからの再照準、Z直後の連続操作を確認し、速度を調整する。

`verify_gum.gd`で飛行時間・到達時の力ゼロ・次更新の収縮・射程端命中・薄い禁止面・移動対象・移動根元・逆順回収・回収寿命を検証する。`verify_controls.gd`で物理X/Z入力と回収中断、`verify_camera.gd`で既存ズームを検証する。実機の視覚と速度感、高速物体の連続衝突は別途確認する。
