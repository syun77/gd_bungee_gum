# マップ用タイルセット仕様

## 目的と位置付け

初期6区画を構築するためのタイルセット制作案。接着・張力・収縮・解除による移動を読みやすくし、同じ地形を足場、支点、障害物として利用できることを優先する。

ゲームルールは `game-direction.md`、物理は `physics-foundation.md`、初期区画は `stage-action-concept.md`、実装責務は `godot-implementation-plan.md` に従う。本書の舞台、美術、寸法は制作開始時の提案であり、実装・プレイ検証済みの値ではない。画像生成やGodotへの組み込みは本仕様の対象外。

## 舞台と美術方針

**ポップな色使いのファミリーレストラン**を舞台とする。客席、カウンター、厨房、配膳・搬入通路を想定し、既存の6区画の床・壁・梁を明るい内装材として表現する。現行マップは地形配置の試作で、家具・調理設備は今後の独立素材として扱う。

- 主材はクリーム色の陶板・化粧タイルと、ミント色の塗装フレーム。コーラルとハニーイエローをアクセントに使い、固定された大きな構造を簡潔な面で描く。
- ファミリーレストランらしさは清潔な陶板、明るい塗装フレーム、案内サインで出す。プレイ面に細かい柄を広げない。
- 赤い髪・灰色と赤の衣装のTeto、ピンク系のガムが背景から分離する配色にする。
- ガム、照準、張力の発光は実行時の表示へ残す。地形へピンクの発光線や接着点を描き込まない。
- キャラクター候補に合わせたドット絵を採用し、真横の正投影、一定の輪郭密度、左上からの弱い固定光を使う。床に奥行きのある上面を大きく描かない。

初期6区画は同じ素材で統一する。別バイオーム、華美な装飾、複数の季節差分は中核操作の検証後に検討する。

## 制作寸法

| 項目 | 制作基準案 |
| --- | --- |
| 論理タイル | 32 × 32 px。マップ座標と静的地形配置の基本単位 |
| 小さい装飾の位置刻み | 16 px。衝突を伴わない装飾に限定 |
| 主な梁・足場の厚さ | 32 px以上。初期版は全方向に衝突する直交形状 |
| 地形シート | 512 × 512 px、16列 × 16行、32 pxセル |
| 画像形式 | 透過RGBA PNG。グリッド線、文字、番号、外付けの影なし |
| 描画 | 補間なし、ぼかし・半透明の輪郭を避ける |
| キャラクター比較 | 立ち姿の見かけ高を約64 px（2タイル）にする比較案から開始 |
| 比較用画面 | 960 × 540の作業用構図。ゲームの正式な基準解像度ではない |

キャラクターの元セル256 pxをそのままタイル寸法へ合わせない。`images/normalized/` の余白を含むセルと人物の可視高を区別し、足元基準と頭・胴体の大きさを維持して表示倍率を決める。32 pxは地形制作単位であり、キャラクターの原画ドット密度まで一致すると仮定しない。

区画の幅、谷の距離、天井高はタイル数だけで確定しない。実測した蹴り出し到達距離、接着射程、ガム最大長、解除後の軌道から決める。蹴り出しだけで必須ギャップを越えられず、ガムで無理なく越えられることを条件にする。

## 地形と物理の読み分け

| 分類 | 見た目の約束 | 判定・役割 |
| --- | --- | --- |
| 固定地形 | 連続した陶板面、床・壁・天井に共通の明確な縁 | 原則、露出した面へ接着可能。静的衝突 |
| 固定鉄骨 | 壁へ埋め込まれた端部、連続した支持構造 | 固定地形と同じ接着規則 |
| 可動物 | 全周の独立した輪郭、持ち手や角の補強、床との分離 | 独立した剛体。移動・回転する接着先 |
| 背景 | 低コントラスト、暗い輪郭、連続する奥の構造 | 衝突・接着・照準遮蔽なし |
| 危険物 | 歯形や警告縞など、色以外でも識別できる形 | 独立した危険判定。接着可否は危険性と別に定義 |
| 出口・区画目印 | 枠と矢印、安定した小さな灯り | 独立した進行判定。装飾タイルだけで機能させない |

接着は専用マークの位置だけに限定しない。床、壁、天井の一般面を等しく利用できる絵にする。初期版では通常地形の接着不可バリエーションを作らず、例外ルールを増やさない。

天井の下面と壁の側面にも床と同じ輪郭の強さを与える。石の目地や鋲は表面模様であり、レイやキャラクターが引っ掛かる凹凸にはしない。見える通路を装飾の衝突で塞がない。

## 初期タイル一覧

1枚の地形シートに以下を収める。未使用セルは透明にし、別表の座標一覧で用途を管理する。

| セット | セル数 | 内訳・用途 |
| --- | ---: | --- |
| 石の基本接続 | 47 | 8近傍の接続形状47パターン。斜め接続は隣接する縦横が埋まる場合だけ考慮。内角・外角・孤立・細い列を含む |
| 石の控えめな差分 | 8 | 中央4、床上縁2、天井下縁2。形状・衝突は対応する基本タイルと共通 |
| 鉄骨 | 16 | 横の左端・中央・右端、縦の上端・中央・下端、四隅、T字4方向、十字、孤立 |
| 背景壁 | 12 | 面4、縦継ぎ2、横継ぎ2、アーチ用部品4。衝突なし |
| 表面装飾 | 8 | ひび2、鋲2、壁パネル2、固定部品2。衝突なし |
| 案内・警告 | 8 | 左右矢印、入口・出口の紋章、区画目印、警告縞2、標的紋章。機能判定は別管理 |
| **合計** | **99** | 地形シートの使用セル。画像ファイル数ではない |

47パターンは絵の接続要件であり、エンジンの自動配置機能への登録数を保証するものではない。制作開始時に47セルの近傍マスクとアトラス座標を一覧化し、欠けた内角や重複を防ぐ。初期試作では手置きでもよい。

装飾差分は同じ衝突形状同士だけで交換する。再配置しても通路幅や接着面を変えない。破壊可能物を想起させる大きな亀裂は、通常地形の装飾には使わない。

## タイルとは別に作る素材

| 素材 | 原画の寸法案 | 扱い |
| --- | --- | --- |
| 軽・中・重の箱 | 各64 × 64 pxの透明枠、見える本体は各48 × 48 px | 同じ基本形の別外観。枠ではなく本体に合わせた剛体形状 |
| 遅い物理弾 | 32 × 32 px | 独立した剛体。背景の丸い模様と区別 |
| 投射装置・標的 | 各64 × 64 px | 固定装置と命中判定を個別シーン化 |
| 出口枠 | 96 × 128 px | 開口部と進行判定を分ける。枠の見える部分のみ必要に応じて衝突 |
| 遠景 | 512 × 256 pxを基本単位とする横反復画像 | アーチや舞台設備。左右端が連続し、プレイ面の輪郭をまねない |

箱の質量差は薄板・補強リブ・密な金属板などの構造と模様で表現する。同じ大きさでも違いが読め、質量を色だけで伝えない。重量箱を地形タイルへ焼き込まない。安定した受け地形へ置き、重くても落下・回転する物体として扱う。

## 配色と視認性

色の方針はバニラクリーム、暖かいベージュ、ミント／ターコイズ、少量のコーラル、ハニーイエロー。輪郭は暖色系の茶色、背景は彩度を抑えたティールとして、明るい地形を分離する。色数は素材ごとに抑え、画面全体で使い回す。

ガム用の鮮やかなピンクと、限界を知らせる明滅は静的背景に使わない。コーラルの面積を絞り、人物の赤い髪と競合させない。地形の外周を最も読みやすくし、内部の模様と背景はそれより弱くする。

グレースケールでも床・壁・天井と空間が分かれること。暗所でも衝突面を隠さず、ガムと照準が明暗両方の地形上で見えること。必要なガムの縁取りは実行時表示側で調整する。

## マップのレイヤーと実装責務

描画は奥から、遠景、背景壁、静的地形、地形表面装飾、物理オブジェクトとキャラクター、ガムと接着点、HUDの順を基本とする。初期版では人物やガムを隠す前景装飾を置かない。

完成ステージを1枚の画像へ統合しない。地形画像は配置と描画、衝突形状は物理、接着可否はゲームルールが担当する。静的地形は既存計画の `Terrain (StaticBody2D)` が保持する形状として構築し、タイル描画との二重衝突を作らない。接着点はアトラスのセル中心でなく、レイが命中した実際の地形面に置く。

初期衝突はグリッドに沿う矩形を基本とし、連続面をつなぐ。絵の切り欠きや縁の装飾は接触面から原画1 px程度を目安に収め、衝突位置の誤認を避ける。タイル継ぎ目で移動・レイ判定が引っ掛からないことを確認する。

箱、投射物、危険物、出口の動作はタイル番号から推測せず、各シーンの設定で管理する。斜面、一方通行床、移動床、壊れる地形は初期セットに含めず、物理ルールと表示を検証してから追加する。

制作原本は `images/tilesets/`、Godotへ取り込む採用素材は `gd-bungee-gum/assets/tilesets/` を配置先案とする。アトラス座標・接続マスク・使用箇所は `specs/` 内で管理し、ゲーム内のシーンとリソースはGodotプロジェクト内に置く。

## 初期6区画への適用

| 区画 | 使用する素材と配置上の要件 |
| --- | --- |
| 蹴り出し | 床・壁・低い天井。接触面と自由空間を明瞭にする |
| 天井スイング | 広い下面を持つ梁と谷。揺れる空間に装飾を張り出さない |
| 軽箱の移動 | 平らな床と段差。可動箱と固定地形の境界を明瞭にする |
| 重箱アンカー | 重箱を受け止める床と谷。箱の質量と支持の状態を読み取れるようにする |
| 物理弾の偏向 | 装置・弾・標的。弾道の背景を簡潔にし、接着の瞬間を隠さない |
| 出口 | 既出素材の組み合わせと大きな出口枠。新しい材質ルールを導入しない |

## 制作順と受け入れ条件

1. 無地の32 px仮タイルと箱で6区画の衝突・接着・クリア経路を検証する。
2. 床・壁・天井と内外角の小さな美術サンプルを作り、Tetoとガムを重ねて縮尺と視認性を確認する。
3. 石47パターンと鉄骨を揃え、接続のテストマップを作る。
4. 可動物、出口、控えめな背景を追加し、6区画全体で確認する。

完成判定：

- 各画像の寸法と整数セル切り出しが仕様に一致し、輪郭の欠け、隣セルの混入、意図しない半透明がない。
- 石の全接続パターンと鉄骨の継ぎ目に隙間や不要な縁が出ない。床だけでなく壁・天井・内角も確認する。
- 表示縮尺でキャラクター、接着点、弛んだガム、張ったガム、物理弾を見分けられる。
- 初見で固定地形、背景、軽箱と重箱、危険、出口を形と明暗で識別できる。
- 見える衝突面と実際の判定が一致し、継ぎ目で引っ掛からず、装飾が照準やガムを遮らない。
- 静的地形の広い面へ接着でき、専用アンカーを探す必要がない。
- 美術適用後も同じ物理条件・入力で各区画の経路が成立する。

この段階では素材数の多さより、**天井へ貼れる、箱は動く、解除後はどこへ飛ぶか**を画面から判断できることを合格基準にする。
