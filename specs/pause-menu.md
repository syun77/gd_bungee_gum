# 一時停止メニュー

OPTIONS（any-device JOY_BUTTON_START、InputMap `pause_menu`）、Escで開く。メニュー表示中はSceneTree全体を一時停止し、箱・ガム・キャラクター・登場/死亡演出も停止する。`pause_menu.gd` のCanvasLayerだけALWAYSモードでUI入力を受ける。

項目は順番に「リトライ」「ステージ選択に戻る」「キャンセル」「リプレイ再生」。最初はリトライにフォーカス。上下で循環、Cross/Enter/Spaceで決定（ui_acceptにCrossを明示登録）、マウス操作も可能。再度OPTIONS／Escもキャンセルとして閉じる。リプレイはゴール済み記録がある場合のみ選択でき、進行中のプレイを終了して専用再生画面へ移る（[リプレイ仕様](replay.md)）。

リトライは現在のステージを入口から再開してチェックポイントを解除する。ステージ選択は選択画面へ戻る。両方とも一時停止を解除してから遷移する。キャンセルは位置・速度・ガム接続・演出経過を保持して再開する。閉じた直後のGame更新を1回消費してUI決定がジャンプや発射にならないようにする。Rはプレイ中の直接リスタートとして維持する。

入口演出中、死亡演出中、クリア後にもメニューを開ける。シーン終了時はメニュー自身が所有している一時停止を解除する。クリア画面のステージ選択ボタンも維持する。

検証は `tools/verify_pause_menu.gd`（実際のOPTIONS/十字/Cross、入口と剛体の停止、勢い保持、キャンセル、リトライ、選択復帰）、`verify_stage_select.gd`、`verify_controls.gd`。
