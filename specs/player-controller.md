# プレイヤー試作

食べ物への命中は専用の引き寄せ状態REELINGへ移行する。引き寄せ中は速度・重力・移動とZ/Xを停止し、手元回収後はZで一度だけ空中ジャンプできる。詳細は [food-gum-reel.md](food-gum-reel.md)。

F5で `scenes/game.tscn` を実行。A/Dまたは左右矢印で走り、Zは接着中なら切断＋真上ジャンプ（下降速度を打ち消し、上昇速度には加算）、未接着なら接触／コヨーテキック、または一度だけ空中ジャンプを行う。Rでステージを再生成する。既存マップの閲覧は `scenes/map_preview.tscn` をF6で実行する。

`CharacterBody2D` の足元を原点とし、幅20・高さ52 pxの固定カプセルで衝突する。正規化済みTeto画像を256 pxセルで切り出し、0.3125倍で表示。待機は6コマ/6 fps、走りは8コマ/12 fpsでループ。空中はjumpの2・3・5番（0始まり）を上昇・頂点・下降に割り当て、着地時は6番を短く表示する。描画は移動や当たり判定に影響しない。接地中は左右入力があるか、横速度が12 px/sを超える場合に走りモーションを再生する。ブロックや壁を押して実移動量がゼロでも、左右入力が続く間は走る。空中・ガム・着地モーションの優先順位は維持する。

左右の意図速度と外部速度を別々に保持し、重力・蹴り出しは外部速度へ加算。地上速度220 px/s、重力1100 px/s²、蹴り出し260 px/s。空中の入力加速度は弱める。床・天井への接触中、または床離脱直後のコヨーテタイム中に蹴り出せる。未接着時は同じ接触中の連打・長押しでは再発動せず、空中ジャンプは着地まで一度だけ。外部速度は衝突面に沿って整理し、入力速度は投影後の横成分だけを保持する。入力速度の縦成分は常にゼロとし、衝突で生じる上向き成分を持ち越さない。ガムの張力は `apply_external_force(force, delta)` で積分する。

カメラはマップ範囲内で追従する。ガムと軽・重の物理箱を実装。方向キーで常時方向を指定し、X押下で先端を発射、到達して接着した次更新から自動収縮する。接着中は下で弛緩・延長、弛緩中の上で手動短縮、Xで自動収縮する。方向指定・発射中も左右移動を継続する。詳細は `bungee-gum-prototype.md` を参照。敵・クリア判定は未実装。全ステージ攻略の合格判定は未完了。

`Game` が毎物理ティック、接続入力→張力→`Player.simulate(delta)`→カメラ・表示の順に更新する。Player自身は `_physics_process` を持たず二重更新を避ける。カメラは移動後の位置を追う。

検証: `Godot --headless --path gd-bungee-gum --log-file /tmp/player-check.log --script res://tools/verify_player.gd`。

接地中の外部速度は床の接線方向に `ground_friction`（初期値900 px/s²）でゼロへ減速する。300 px/sの外部速度は約0.33秒で停止する。着地したティックから適用し、左右入力・照準・接続の有無に依存しない。空中と床から離れる蹴り出しには適用せず、入力速度の加減速は従来どおり別に処理する。

調整値は共有設定 `resources/game_settings.tres` のPlayer Movementで編集する。編集手順と表示設定は `game-settings.md` を参照。

接地キックの使用可否は、床に接触しているティック、または床・壁・天井すべてに接触していないティックで回復する。壁に接触し続けて着地しても床キックを再使用できる。壁／天井だけの継続接触では回復せず、未接着かつコヨーテタイム外の空中では、壁接触中も未使用の二段ジャンプを使用できる。壁キックは行わず、壁接触だけではジャンプ回数を補充しない。

床離脱時の入力猶予（コヨーテタイム）は共有設定`coyote_time`（初期値0.20秒、0で無効）で制御する。床接触中に残り時間を更新し、非接地ティックで時間を減らす。非接触でも残り時間があれば真上へ一度だけ接地キックを加算できる。床・天井でのキックを含め、成功したキックは猶予を消費する。壁／天井の離脱では猶予を補充せず、床離脱後は、新しいZ入力で一度だけ二段ジャンプできる。Zのガム切断はキック判定より先に行う。

コヨーテキック直前には、離床後に重力で増えた速度のうち、下向き成分だけを補正する。補正量は現在の外部速度の同方向成分以下に制限し、真上への蹴り出しを加算する。横速度・上向きの勢い・重力分を超えるガムや衝突由来の落下速度は保持する。重力の補正用速度も実際の衝突法線で投影し、地形が既に取り除いた分を補正に再利用しない。床接触で補正用速度をリセットし、猶予切れまたはキック成功で消去する。床キックも真上へ加算し、天井の接触キックは下向きを使う。接地法線は接触判定・衝突処理・摩擦に使用し、床・コヨーテのキック方向には使用しない。

## ブロック接触・支持と圧縮

入力・重力・キックを速度へ反映した後、`move_and_slide()`より先に壁・天井相当の剛体接触を解く。プレイヤー本体の幅20・高さ52 pxカプセルは保持し、反発用カプセルだけを`contact_clearance`（初期値0.75 px）広げる。2 px以内の凍結していないレイヤー4剛体の各有効形状との`collide_and_get_contacts()`で接触点・法線・深度を取得する。形状判定ではライブの衝突マスクを変更しない。

法線と`up_direction`の内積がcos(`floor_max_angle`)以上の接触は支持面とし、反発用の余白・分離速度・反発係数を適用しない。支持判定と着地は実カプセルの`move_and_slide()`に委ねる。実際の剛体支持接触で除去した外部運動量は、その接触点への逆向きインパルスとして剛体へ渡す。支持面上に静止するための重力反作用もこれに含む。接線方向の床摩擦は独立して適用する。

非支持接触は接触点での並進・角速度、実質量・重心・慣性を用いる。反発係数`contact_restitution`（0.1）は接近速度30 px/s超で適用する。分離目標速度はmax(反発用接触深度−0.05 px,0)×`contact_penetration_response`（0.8）÷deltaを`contact_separation_speed`（120 px/s）で制限した値と反発分の和。8回の逐次インパルス解法で、各接触の有効逆質量（プレイヤー逆質量＋剛体逆質量＋レバー腕外積の二乗×逆慣性）と更新済み速度を使い、累積インパルスを非負に制限する。すでに十分な分離速度がある接触には追加しない。

解法内の剛体速度は仮想状態へ更新し、同量の逆向き運動量をプレイヤーへ反映する。剛体への実インパルスは、プレイヤーの移動・地形補正・速度整理がすべて終わってから接触点へ一括適用する。これにより、反作用で同じティックに生じる一時的な剛体速度を自動足場追従が拾うことを防ぐ。`platform_floor_layers`は通常の全レイヤー設定を保ち、実際に移動・上昇する剛体足場には追従する。sleep中の剛体は必要なインパルスで起こし、剛体の位置・回転やガムの状態は書き換えない。

移動後に地形へのめり込みが残り、近くに動く剛体がある場合は、近接剛体RIDを除外したゼロ移動`body_test_motion`で復元量を調べる。0.01 px以上なら余白`safe_margin+0.25 px`で最大8回、物理エンジンの結果を適用する。補正方向の剛体へ質量×（補正距離÷delta＋接近速度）の反作用を返す。実際に地形補正した場合だけ、剛体レイヤーを除いた微小移動で支持判定を更新する。通常の支持フレームでは問い合わせのために衝突マスクを変更しない。

`Pinning Diagnostics`の`CONTACT_IMPULSE`は`kind=repel/support`で接触用途を区別し、相手・位置・法線・深度、分離目標速度、インパルス、剛体速度の適用前後を記録する。`COMPRESSION_RECOVERED`は地形補正量を示す。各30物理ティック間隔。通常の接触スナップショットには足場速度と追従レイヤーも含む。

`tools/verify_compression.gd`は左右の壁・1 kg/6 kgブロック間の継続圧力、質量差・回転・ガム収縮、単体衝突の即時解法／遅延適用、運動量保存と偏心トルク、分離中の追加反発抑制を検証する。支持については中央・左右端寄りの無入力着地、連続接地・浮き／横滑り防止・idle・キック脱出、水平移動／上昇中の実剛体足場への追従を確認する。`-- --support-only`で支持、`-- --two-block-only`で圧縮・衝突を個別実行できる。

## 角での床支持

矩形の上向き支持面にカプセル底面が触れた場合、実接触法線と床支持法線を分ける。衝突形状のインデックス・接触点・ワールド変換から矩形の4辺を調べ、接触点から0.5 px以内にある床角度内の辺の外向き法線を、速度整理と床摩擦に共通で使う。回転した矩形も実際の辺方向を使い、実斜面を水平面に置き換えない。壁・天井、矩形以外、辺を確認できない接触は実法線を使う。

水平な支持面では下向きの外部速度を受け止め、落下から横速度を発生させない。持ち込み横速度は摩擦で減速し、上向きのガム・キックは離床できる。接地判定・移動・衝突法線はエンジンが所有し、位置固定や床フラグの上書きはしない。剛体への支持反作用は、同じ速度整理で除去した運動量から求め、実接触点へ移動後に適用する。

`verify_player.gd`は左右の元の足場で、端から0/3/5/7/9/9.8/9.99 px・初期落下速度0/300/600 px/sの42条件について、着地フレームの横変位0.1 px未満と90ティック内の継続支持を検証する。下向き追加荷重・上向き離床・横運動量の保持と端からの離脱、回転した支持面の法線も確認する。

端の接触法線が床角度を超えていても、実際の矩形辺が床角度内なら支持候補とする。移動前の`test_move()`でその接触を確認し、下降・水平移動時に限り、その移動呼び出しだけ接触法線を床分類できる角度へ広げる。設定角度は呼び出し直後に戻す。上向き離床、真の側面・下面、支持不能な斜面には例外を適用しない。

すでに接地している場合は、確認できた支持面に向かう移動速度を移動前に除去し、床スナップと実接触で支持を維持する。これにより毎ティックの重力移動が丸い角へ食い込み、復元変位が横ずれを生むことを防ぐ。外部速度自体はこの時点で変更せず、移動後に実接触で整理し、剛体への反作用を保持する。近接剛体の非支持反発判定も形状インデックスを持ち、同じ支持面判定を使う。

追加回帰では斜め下降時の押し返し防止、真の壁・天井が床扱いされないこと、床角度設定の復元も検証する。静的地形の角で見られる横の押し返しは、下向き速度の斜め接触面への投影でも発生し、剛体の反発設定とは別の経路である。

## ジャンプと着地の見た目の伸縮

上向きのキックが成立し、発進速度も上向きの場合、スプライトを横0.84倍・縦1.41倍に伸縮する。0.31秒で二次曲線状に通常サイズへ戻す。床・コヨーテ・ガム解除ジャンプに共通で、成立しないジャンプ入力は再発動しない。

既存の `landed` イベントと同じ条件を満たす着地では横1.44倍・縦0.82倍に潰し、0.31秒で戻す。初期配置の接地、短い接触の揺れ、圧縮回復は対象外。新しいジャンプ／着地は進行中の伸縮を置き換える。

`Player` は物理ステップでアニメーション選択後に `AnimatedSprite2D` の scale と position だけを更新する。足元を基準に変形し、CharacterBody2D・固定カプセル・物理的なガム原点・移動速度は変えない。ガムの描画用手元位置はスプライト変形を追従する。係数と時間は共有 `resources/game_settings.tres` の `Player Squash and Stretch` で調整する。`jump_stretch`／`landing_squash` は横・縦倍率、`jump_stretch_duration`／`landing_squash_duration` は復元秒数（0で該当効果を無効化）。

検証: `tools/verify_player_deformation.gd`（実ジャンプ／着地、入力拒否、足元基準、当たり判定不変、復元）。

### 高速移動の残像

高速移動時の残像は `Player Afterimages` 設定で調整する。実移動距離÷固定ステップ秒数が `afterimage_minimum_speed`（350px/s）以上なら、`afterimage_interval`（0.04秒）ごとに表示中のフレーム・向き・変形をワールド座標に固定して複製する。通常走行220px/sでは発生せず、落下・ジャンプ・ガム移動にも同じ速度条件を使う。薄いピンク `afterimage_color`（RGBA 1/0.72/0.85/0.32）が `afterimage_lifetime`（0.20秒）で二次減衰し、最大8枚。減速後も既存の残像は消えるまで残る。`afterimage_enabled=false` または寿命0で消去・停止する。Playerの子として再スタート時に破棄され、当たり判定や運動には影響しない。

残像は元のプレイヤー画像の実効Zより1低い絶対Zで描画し、常にプレイヤーの背面に置く。

残像は `shaders/afterimage_silhouette.gdshader` の単色シルエットで描画する。元画像からはアルファだけを使い、RGBは `afterimage_color`、不透明度は同色のアルファとフェードから決める。共有マテリアルを使い、プレイヤー本体の色は変更しない。

### ジャンプバッファ

共有設定 `Player Movement/jump_buffer_time`（既定0.12秒、0で無効）で着地前のZ／Cross入力を保存する。期限内に床へ着地すると、床接触を確認した最初の物理ティックで通常の床キックを一度だけ実行する。ボタンを離しても有効だが、押し続けての自動連続ジャンプはしない。天井キック、ガム切断と付着ジャンプ、フード報酬ジャンプは新しい入力で発動する。成功したキック・一方通行床の降下・移動リセット・フード回収ロックは未消費入力を消去する。回収ロック中の入力は保存しない。

ハシゴ範囲内では上下で昇降（Ladder / ladder_speed既定120px/s）。左右・Z・ガム発射で離れる。詳細は [ladders.md](ladders.md)。

## 二段ジャンプ

Z／Crossの押し直しで、空中で一度だけ真上へジャンプできる。床接触または地形・剛体・リングへのガム接着成立で1回分を回復する。壁接触やフード回収では補充しない。足場から歩き落ちた場合も使用できる。床／天井・コヨーテ・ガム解除・フード報酬・ハシゴの既存ジャンプを優先し、これらは空中ジャンプ枠を消費しない。REELING中と下抜け操作時は発動しない。

初段・接触・コヨーテ・ガム解除・フード報酬・ハシゴの強さは `Player Movement / Kick Speed` (`kick_speed`)。二段目だけは `Player Double Jump / Double Jump Kick Speed` (`double_jump_kick_speed`) で独立して設定する。二段ジャンプの発動更新では上昇・下降を問わず既存の縦速度を置き換え、`external_velocity.y = -double_jump_kick_speed` を代入する。その更新の重力も発進速度に影響しない。横速度は保持し、次の更新から通常の重力を再開する。二段目の成立から着地・ハシゴ把持・ガム接着まで、専用の膝抱え `double_jump` ポーズをスプライト中心で共有設定 `Player Double Jump / Double Jump Rotation Speed`（既定2.5回転/秒＝0.4秒に一周）で回転させる。発射中は膝抱えポーズを維持し、接着時には回転をゼロへ戻して通常のガムポーズ選択へ戻る。移動リセット／回収ロックでも回転を解除する。回転は描画だけに適用し、当たり判定・ガムの物理原点・速度・重力・操作性能は変えない。

空中枠が残っていれば着地前の入力は即座に二段ジャンプとして消費し、使用済みなら通常の着地ジャンプバッファに保存する。検証は `tools/verify_double_jump.gd`。

回転ジャンプの向きは表示中のキャラクターに従い、右向きは時計回り、左向きは反時計回り。空中で左右入力により振り向くと、角度をリセットせずその更新から逆回転する。無入力時は直前の向きを保持する。`double_jump_rotation_speed` は両方向共通の速さで、移動速度や外部運動量には影響しない。

ガム接着では既存の速度・張力処理を変えずに回転だけを停止し、二段ジャンプ枠を1回分に戻す。接続を保持している間は繰り返し補充しない。接着中のZは切断ジャンプ、その次の新しいZで回復した二段ジャンプを使える。空振り・飛行中・回収中では補充せず、フード命中は専用REELINGと報酬規則に従う。検証: `tools/verify_double_jump_gum.gd`。
