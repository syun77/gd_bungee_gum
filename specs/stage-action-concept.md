# ステージクリア型物理アクション企画

## 企画概要

バンジーガムを地形、敵、物体、飛び道具へ接着し、張力を蓄えて移動・攻撃・防御へ変換しながらゴールを目指す、横視点のステージクリア型2D物理アクションとする。

各ステージは、数分で再挑戦できる複数の区画から構成する。通常ジャンプに依存せず、接着、振り子、収縮、解除、地面や壁からの蹴り出しによって高度と速度を作る。プレイヤーは正解ルートをなぞるのではなく、物理関係を読み、自分の軌道と攻略順を組み立てる。

仮の一文紹介は次のとおり。

> 貼り付け、伸ばし、弾き飛べ。敵の攻撃さえ足場と推進力に変える、ステージクリア型ラバーアクション。

## 参考作品から継承する設計思想

### 『ヒットラーの復活 TOP SECRET』から学ぶこと

通常のジャンプを持たず、ワイヤーによる移動を例外的な補助ではなく、ステージを読むための基本言語にする。ワイヤーで天井へ接続し、上昇、ぶら下がり、スイングを使い分けることで、一般的な横スクロールとは異なる地形認識を要求する。

本作でも「普通に跳べば済む」配置を減らし、接着点、落下経路、振り子の支点、解除後の着地点を読むこと自体をゲームにする。ただし、固定された専用アンカーだけを使うのではなく、広い地形面と動的対象へ接着できる点で発展させる。

### 『海腹川背』から学ぶこと

ゴムのように伸縮するロープへ荷重をかけ、縮む反動と振り子運動を組み合わせることで、単純なフック移動を高い技術表現へ変える。出口へ到達するという明快な目的に対し、張力の作り方と解除タイミングによって多様な軌道が生まれる。

本作でも、入力に対して毎回同じ必殺技を再生するのではなく、位置、速度、長さ、張力から結果を生成する。初心者は安全な振り子で進め、熟練者は反動を連鎖させて地形を高速突破できる二層構造を目指す。

GAME Watchのレビューでは、『海腹川背』の特徴を、ゴムのように伸縮するロープへ荷重をかけ、縮む反動で加速し、振り子運動を作るアクションとして説明している。また、偶然性が少なく、習熟によって新しい攻略が可能になる点を評価している。[GAME Watch「海腹川背・旬 セカンドエディション完全版」レビュー](https://game.watch.impress.co.jp/docs/review/336163.html)

## 本作独自の中心

参考作品との差は、ガムの端点が地形だけに限定されないことである。

- 敵を自分へ引き寄せる。
- 重い敵へ自分が引かれ、移動アンカーとして使う。
- 飛び道具を捕捉し、振り回して別の敵へ返す。
- 箱を引き寄せ、足場、盾、投射物として使う。
- 動く敵へ接着し、その移動を利用して谷を越える。
- 敵と危険物を接続し、相手の行動そのものを罠にする。

同じ対象が、障害、足場、武器、錘、推進源へ変わることがバンジーガム固有の遊びになる。

## ゲームの中心命題

各瞬間にプレイヤーへ問うのは、次の3点である。

1. **どこへ貼るか**
2. **どう張力を作るか**
3. **いつ縮め、いつ離すか**

攻撃ボタンの強弱や装備相性ではなく、この判断と実行がプレイヤーの上達になる。

## 移動設計

### 通常ジャンプを廃止する

自由な通常ジャンプは持たせない。通常ジャンプがあると、小さな高低差や敵回避をガムなしで解決でき、ステージ設計が一般的なプラットフォーマーへ戻りやすいためである。

代わりに、床、壁、天井へ接触しているときだけ使える短い**蹴り出し**を持たせる。蹴り出しは単独で高所へ届く移動技ではなく、次の用途へ限定する。

- 振り子運動の初速を作る。
- 張ったガムへ荷重を加える。
- 壁から離れて照準角度を作る。
- 着地後に運動量を次の接続へつなぐ。

空中ではガム以外の強い推進手段を持たせない。これにより、ワイヤー移動を必須にしながら、静止状態から振り子を開始できない問題を解消する。

### 基本移動技

- **プル**: 上方または前方へ接着し、収縮して引き寄せられる。
- **スイング**: 支点の下で左右入力と重力を使い、振幅を増やす。
- **リリース**: 最大速度に近い位置で解除し、接線方向へ飛ぶ。
- **バウンド**: 地面や壁への接触時に蹴り出し、残った運動量を次の軌道へつなぐ。
- **リバース**: 進行方向の反対側へ接着し、張力で急減速または方向転換する。
- **ロケット**: 足元または後方へ接着してガムを伸ばし、収縮反動と蹴り出しを重ねて射出する。
- **キャッチ**: 落下中に接着し、張力で衝撃を吸収して別方向へ変換する。

技名は個別スキルではなく、共通物理から生まれる操作パターンを説明するための呼称である。

## 操作

キーボードのZ/X操作を使用する。詳細は `keyboard-controls.md` を参照。

| 入力 | 操作 |
| --- | --- |
| 左右矢印／A,D | 地上移動、空中の意図速度調整 |
| Z | 切断と接触面からの蹴り出し。空中では切断のみ |
| X長押し＋方向キー | 未接着時に8方向照準。照準中は移動入力を抑制 |
| 照準中のX解放 | レイで接着し、自動収縮を開始 |
| 接着中のX押下 | 緩め／収縮を1回切り替え |
| R | 現在のマップ全体を即時再生成 |

接着時は自動収縮し、Xで自然長に余裕を作って固定することで、振り子へ移る。再度Xで収縮し、Zで運動量を保って飛び出す。解除はZの明示操作と安全解除によって行う。

照準線、接着予定点、収縮／緩めモード、実際の張力を区別して表示する。照準補正・予測軌道・入力バッファは追加検証対象であり、現在は導入しない。区画単位リスタートは区画進行の実装時に追加する。

## ステージ構造

### 基本単位

1ステージは、およそ3〜8分で初回クリアできる規模を目安とし、3〜5区画で構成する。

1. **導入区画**: そのステージの物理要素を安全に提示する。
2. **展開区画**: 要素を地形移動へ応用する。
3. **干渉区画**: 敵や動く物体が加わり、状態が変化する。
4. **統合区画**: 複数要素を連続で使うクライマックス。
5. **出口**: 到達すればクリア。任意の上級ルートを合流させる。

すべてのステージが5区画を持つ必要はない。短い技巧ステージや一画面チャレンジも許容する。

### チェックポイント

区画の境界をチェックポイントとする。死亡、落下、物理オブジェクトの詰みでは現在区画だけを即座に初期化する。ロード、長い死亡演出、残機制は使わない。

上級者向けには、チェックポイントを使わずステージ全体を連続突破するタイムアタックを用意できる。

### ルート設計

各ステージに最低2種類の攻略感を用意する。

- **安全ルート**: 接着点が多く、低速で姿勢を立て直せる。
- **技巧ルート**: 接着回数が少なく、運動量を維持すれば短時間で突破できる。

技巧ルートを鍵や能力値で閉じず、開始時からプレイヤーの技量で利用できるようにする。ショートカットは物理法則の理解に対する報酬とする。

## ステージクリア条件

基本条件は出口への到達とする。目的の明快さを保ち、攻略方法を物理システムへ委ねる。

変化を付ける場合も、次のように移動と物理操作へ直接つながる条件だけを使う。

- 重いコアを出口まで運ぶ。
- 複数の物理ロックを解除して出口を開く。
- 追跡者から逃げながら出口へ到達する。
- 大型敵の部位を地形へ接続し、動きを止める。
- 崩壊する区画を連続スイングで脱出する。

収集物の全回収や敵の全滅を通常クリアの必須条件にはしない。

## 戦闘

戦闘はステージ移動を中断する別モードにしない。敵を倒すことより、敵をどの物理的役割へ変えるかを重視する。

### 基本的な無力化方法

- 壁や床へ衝突させる。
- 別の敵や飛来物と衝突させる。
- 危険地形へ引き込む。
- 地形へ接着して動きを制限する。
- 攻撃を捕捉して撃ち返す。
- 重量物を落下または振り回して当てる。
- 敵をアンカーとして利用し、戦わずに通過する。

敵を通過してもよい場面を多くし、速度を維持することと安全に排除することの選択を作る。

### プレイヤーの直接攻撃

初期プロトタイプでは独立した通常攻撃を持たせない。プレイヤー自身の高速衝突、物体の投射、敵の攻撃の反射を攻撃手段とする。

直接攻撃が後に必要になっても、敵を倒す主役にはせず、接着機会を作る、姿勢を崩す、軽い物体を動かすための補助に限定する。

## 敵とギミック

### 敵

- **ランナー**: 足場を往復する軽量敵。投射物にも移動アンカーにもなる。
- **チャージャー**: 直線突進する中量敵。張力へ大きな運動量を供給する。
- **シューター**: 物理弾を撃つ。弾丸を捕捉・反射する教材になる。
- **タンク**: 重量敵。動きにくいが強力な移動アンカーになる。
- **カッター**: ガムへ接触すると切断する攻撃を持ち、接続の維持時間を制限する。
- **フライヤー**: 空中を移動する支点。接着すると互いの軌道が変化する。

### ギミック

- 動く足場とレール
- 落下する錘
- 回転アーム
- 反発面と粘着不能面
- 破壊可能な梁
- 張力で作動するレバー
- 物理弾を撃つ砲台
- ガムを切断する刃
- 質量を変える荷物
- 接続点を運ぶ移動ドローン

専用ギミックは共通物理を変えるのではなく、接続候補、運動量、時間圧を変化させる。

## ステージ案

### Stage 1: 接着塔

目的は上方の出口へ到達すること。固定壁への接着、収縮、解除、簡単な振り子を順番に学ぶ。最後は一つの長い振り子で安全ルートを飛び越えられる。

### Stage 2: 貨物区画

軽・中・重の箱が登場する。軽い箱は引き寄せ、中量箱とは双方が動き、重量箱には自分が引かれる。出口は重量箱をアンカーにして谷を渡った先にある。

### Stage 3: 砲撃回廊

砲台の弾を避けるだけでなく、ガムで捕捉して扉の物理ロックへ当てる。上級ルートでは弾丸の運動量を利用して自分を高速射出する。

### Stage 4: 生きた足場

軽量敵と飛行敵が主な接着点になる。敵を倒すと足場を失うため、利用してから無力化する順序が重要になる。

### Stage 5: 崩落シャフト

下から崩壊が迫る縦長ステージ。固定アンカー、落下物、飛行敵へ連続で張り替え、運動量を失わず上昇する。理解済みの操作を時間圧の中で統合する。

### Boss: 巨大クレーン

ボス本体の体力を削るのではなく、左右のアーム、吊り荷、支柱へガムを接着する。ボスの振り下ろしで張力を作り、その力で支持部を破壊する。攻撃を避けることと攻略ギミックが同じ物理関係になる。

## スコアと再プレイ

クリア自体は出口到達だけで認める。評価は攻略を縛らず、異なる上達を可視化する。

- クリアタイム
- リスタート回数
- 接着回数
- 最大連続滞空時間
- 最大速度
- 任意のチャレンジ目標

総合ランクは、初回プレイヤーに最適解を強制しやすいため必須にしない。各記録を個別に残し、タイムアタック、少接着、ノーリスタートなど別々の遊びとして扱う。

ゴースト、自己ベスト軌道、区間タイムは、物理操作の改善を理解する助けになる。

## 難易度設計

難易度は必要な精度だけで上げない。次の順で複雑化する。

1. 接着点の位置を読む。
2. 張力と解除タイミングを読む。
3. 動く接着点を使う。
4. 質量差を使う。
5. 複数の外力が重なる。
6. 敵が接続状態へ干渉する。
7. 連続動作で運動量を維持する。

各新要素は、低圧の導入、単独での確認、既存要素との組み合わせ、高圧での応用という順序で提示する。

## 初期プロトタイプへの変更

既存の一画面プロトタイプを、次の短いステージへ発展させる。

1. 床と壁からの蹴り出し
2. 天井接着による振り子
3. 軽い箱の引き寄せ
4. 重い箱をアンカーにした谷越え
5. 物理弾の捕捉と標的への反射
6. 出口到達と区画リスタート

通常ジャンプと独立した通常攻撃は実装しない。まず、この6区画だけで移動、物体操作、戦闘的応用が連続した一つのゲームとして成立するかを検証する。

## 採用判断

本作は『ヒットラーの復活』のようにワイヤーを通常ジャンプの代替となる移動言語へ引き上げ、『海腹川背』のように伸縮と張力を技量表現の中心に置く。その上で、地形だけでなく敵、物体、飛び道具へ接着できるバンジーガム固有の相互作用を中心にする。

結果として目指すのは、単なるワイヤー移動ゲームでも、静的な物理パズルでもない。**ステージ内のあらゆる運動を接着し、自分の次の軌道へ作り替えるゲーム**である。
