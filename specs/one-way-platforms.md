# 一方通行床

## 配置

`gd-bungee-gum/scenes/stages/theater_stage.tscn` の `OneWayPlatforms`（TileMapLayer）を選び、TileSetのsource ID 1 `restaurant_one_way_platform.png` を描く。32pxグリッドで、左端(0,0)、中央(1,0)、右端(2,0)、単独(3,0)を使用する。左右反転・回転は使わず、上面を上向きに保つ。現在のステージは15本・76セルを持ち、128pxのガム登り後の着地、64pxの蹴り出し、回復ルートに配置する。正本は `scripts/stage_layout.gd`。詳細は `specs/theater-stage-map.md` を参照。F5でプレイ、F6でステージまたはマッププレビューを確認できる。

このレイヤーは `collision_enabled=true`。各タイルが衝突を持つため、描画・消去に伴って判定も更新される。通常地形の `TerrainTiles` と異なり、別のTerrain矩形や輪郭線は追加しない。全マップ再生成ツールにも同じ素材と地形配置を定義するが、実行すると既存の手編集は上書きされる。

## 物理と操作

Godot標準のTileSet物理ポリゴンを使う。セル中心基準の矩形(-16,-16)〜(16,-11)、一方向衝突ON、margin1px。画像の厚みは10px、衝突ポリゴンの厚みは5px。見た目と衝突の上端はセル上端に一致する。物理レイヤー4（ビット値8、OneWayPlatforms）に分離し、プレイヤーmask13、箱mask9で衝突する。箱は既存の通常地形との衝突にビット8を追加する。接触の解決は物理エンジンに任せ、テレポート・着地アニメーションで置き換えない。

端の接触ではTileMapLayerの衝突RIDから凸ポリゴンの実面を求め、床面法線を接地分類・速度整理・摩擦に共用する。カプセル端の斜め接触によって下向き速度を横向き速度へ変換しない。削除済みタイルのRIDは参照しない。接触のない位置へ吸着する処理は行わない。

下から上昇中は通過し、上から下降すると着地する。横からの進入は遮らない。着地後は通常の床と同じ摩擦、接地判定、Zの上向き蹴り出しとコヨーテ規則を使う。一方通行床に接地中は下＋Z（パッドは下＋×）で上向きキックをせず降りる。ガム接着中は切断して降りる。下入力だけでは降りない。通常地形では下＋Zも通常のキック。下抜け開始時は下向き速度を最低60px/sにし、水平運動量は保持する。一方通行床の衝突だけを一時無効化し、開始位置から足が58px下がった時、または0.5秒後に復帰する。コヨーテ猶予は消費し、食事回収の空中ジャンプ権は保持する。自由な空中ジャンプは追加しない。

ガムの接着・遮蔽・静的巻き付き判定はmask5のまま。一方通行床はガムを遮らず、接着・巻き付きの支点にならない。通常の厚い地形とはこの点でも区別する。

## 検証

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path gd-bungee-gum --log-file /tmp/one-way-check.log --fixed-fps 60 --script res://tools/verify_one_way.gd
```

保存済みレイヤーの配置数と4タイルの設定、独立した入口の検証配置で実Playerの上向き通過・着地・Z蹴り出し、1000px/sの落下と継ぎ目への着地、側方通過、実RigidBody2D箱の上向き通過と静止、ガムのレイ通過、単独タイルの追加・消去による衝突更新を検査する。

端の回帰検査は左右端から外側0/5/7/8pxで下降し、60tickの支持継続と横ずれ0.1px未満を確認する。丸いカプセルの接点では足原点が上面より下になる場合がある。
