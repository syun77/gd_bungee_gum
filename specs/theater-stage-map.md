# ファミリーレストラン・ステージのマップ

## 開き方

Godotプロジェクト本体は `gd-bungee-gum/project.godot`。初期マップは `scenes/stages/theater_stage.tscn`、F5のメインシーンは `scenes/map_preview.tscn`。

プレビューの矢印キーでカメラ移動、1〜6で区画移動、Tabで全景と入口を切り替え、Homeで入口に戻る。プレイヤー、ガム、箱、弾、進行判定はまだ実装していない。出口表示と警告縞は配置目印であり、クリアや落下復帰の判定ではない。

舞台の美術はポップなファミリーレストラン。クリーム・コーラル・ミントのタイルとティールの背景を使用する。家具や厨房設備は未配置。

## 地形配置

32 pxグリッド、160 × 24セル（5120 × 768 px）の横長試作。左上が原点、右が進行方向、下が重力方向。区画は連続した同じ物理空間で、番号は編集・将来の区画制御用の目安。

| 区画 | 主なX範囲（セル） | 地形の目的 |
| --- | --- | --- |
| 01 CONTACT | 2–24 | 広い入口床、左壁、96 pxの段差。接触からの蹴り出しと引き寄せの準備 |
| 02 SWING | 25–54 | 広い天井梁、谷、低い回復足場2つ、対岸。天井接着と解除タイミング |
| 03 LIGHT CARGO | 55–79 | 平坦な作業床、高い出口段差、上方梁。軽箱を引くための空間 |
| 04 HEAVY ANCHOR | 80–108 | 高所の箱受け、深い谷、中継足場、対岸。重量物を支点にする空間 |
| 05 REDIRECT | 109–131 | 長い床、低い遮蔽2つ、上方梁。物理弾を扱う視界 |
| 06 EXIT | 132–157 | 段違いの足場と高所の出口床。移動操作を組み合わせる終端 |

床・壁・天井は専用アンカーだけに接着を限定しない想定。ガム距離・蹴り出しの高さ・体格が未実装のため、各ルートの到達可能性や難易度は未確定。特に箱受けへのアクセスと出口の登りは物理試作で調整する。

## Godot内の構成と編集

- `Background` / `BackgroundIron`: 衝突なし、低コントラストの背景柱と塗装フレーム。
- `TerrainTiles`: 地形のタイル描画。陶板地形ID 56–59を使用。手置きで編集可能。
- `Terrain`: 物理レイヤー1の `StaticBody2D`。24個の連続矩形を担当し、タイル単位の物理面を作らない。
- `Rim00`〜: 各矩形に対応する2 pxの輪郭。地形の衝突境界を読みやすくする。
- `Signs`: 衝突なしの案内・警告タイル。区画名は別Label。
- `PlacementMarkers`: プレイヤー、軽箱、重箱、投射装置、標的、出口、6区画の基準位置。実体やチェックポイント機能は持たない。

タイルの追加・削除と対応する衝突矩形・輪郭は一緒に編集する。TileSetには105セルを登録しているが、全レイヤーでタイル衝突は無効。描画側と `Terrain` の二重衝突を避ける。背景や案内のタイルに地形判定を追加しない。

制作原本は `images/tilesets/theater_tileset.png`、採用コピーとTileSetリソースは `gd-bungee-gum/assets/tilesets/`。32 pxセル、余白・間隔0、nearest表示。自動接続設定はなく、生成アトラスの継ぎ目は残る。現段階は既存素材による配置試作として扱う。

## 再生成と検証

プロジェクトルートを `gd-bungee-gum/` としてGodotに渡す。

```sh
Godot --headless --log-file /tmp/map-build.log --path gd-bungee-gum --script res://tools/build_theater_stage.gd
Godot --headless --log-file /tmp/map-check.log --path gd-bungee-gum --script res://tools/verify_theater_stage.gd
Godot --headless --log-file /tmp/map-run.log --path gd-bungee-gum --quit-after 5
```

再生成は保存済みのマップシーンとTileSetを上書きする。手動編集を維持する場合は実行しない。

Godot 4.5.1で保存済みシーンのロード、1,222個の地形セル中心の物理判定、24矩形、主要6マーカーが地形内に埋まらないこと、プレビュー起動を確認。OpenGL描画の全景・拡大画像も確認済み。サンドボックスのheadless実行ではOS証明書取得の警告が出るが、マップ検証と実行は終了コード0。プレイヤーの衝突滑走、接着レイ、ガムによる踏破、落下復帰は今後の実装・検証対象。
