# タイルマップエディタ作成の基本方針

ファイル操作や Undo / Redo の共通方針は [ツール作成.md](./ツール作成.md) に従う。

## データ構成と新規作成

- タイルセットとマップは別ファイルに保存する。タイルセットは画像とタイル ID の対応を持ち、マップは寸法とレイヤー別の配置を持つ。描画レイヤーごとに使用するタイルセットを参照し、同じセットを複数のマップで共有できるようにする。
- マップの新規作成時に幅・高さをセル数で、セル幅・高さをピクセル数で指定する。画像の切り出し寸法は別に扱う。座標は左上原点で右が列、下が行の正方向とし、既存形式の規約を優先する。
- タイルセットエディタで画像を読み込み、画像全体またはアトラス内の領域をタイルとして登録する。アトラスでは切り出し寸法・余白・間隔を指定できるようにする。
- 独自形式では登録時にセット内で一意の ID を指定できるようにし、画像の差し替えや表示順の変更でも ID を維持する。参照中の ID の変更・削除は、参照を更新できる仕組みが整うまで禁止する。Godot のネイティブ形式ではソース ID・アトラス座標・代替タイル ID の組を保つ。
- 初版は描画レイヤーへの手動配置を基本とする。衝突などセルごとの意味や、開始地点などのオブジェクトを扱う場合は、画像の配置とは別のレイヤーに持たせる。自動描画を追加する場合は、セルの意味を元データとし、周囲の値に基づいて見た目を生成する。

## タイル配置と範囲操作

- マップの隣に独立したタイルセットパネルを置き、アクティブレイヤーのパレットと選択中のタイルを表示する。マップ上ではセル座標と配置プレビューを表示する。
- パレットを左クリックしてブラシを選ぶ。マップ上のスポイトは専用ツールとし、アクティブレイヤーから採取したらブラシへ戻る。空セルを拾った場合は選択中のタイルを維持する。
- ブラシは左クリック・左ドラッグで配置、右クリック・右ドラッグで消去する。ドラッグ時は入力イベント間の通過セルを補間する。グリッド外や非アクティブレイヤーは変更しない。
- 矩形選択、矩形塗り、バケツ塗りをツールバーで切り替える。矩形選択は左ドラッグで範囲を作り、Delete で消去、Esc で解除する。矩形塗りはドラッグ中にプレビューし、ボタンを離すと確定する。
- バケツ塗りは同じ ID の上下左右につながったセルを置き換える。空セルも対象とし、マップ端と選択範囲で探索を止める。選択中の編集は範囲内に限定する。一筆の描画・消去や一括編集は、操作ごとに 1 回の Undo にまとめる。

## ミニマップと画面移動

- ミニマップには全体を縦横比を保って収め、メインビューの可視範囲を一定の線幅の矩形で重ねる。ミニマップ内のクリック位置をマップ座標へ変換し、倍率を保ったままメインビューの中心を移す。地図外の余白はクリック対象から外す。
- マップ上のホイールはカーソルを基準にズームする。倍率に上下限を設け、目標倍率まで滑らかに補間する。補間中もカーソル直下のマップ座標を保ち、描画とセル判定で同じ表示変換を使う。「全体表示」と「100%」を用意する。
- 中ボタンドラッグまたは Space＋左ドラッグでパンする。Space を離したら元のツールに戻す。対応環境ではトラックパッドの二本指スクロールでパン、ピンチでズームする。入力はポインター下のパネルで処理し、パンやミニマップ操作でタイルを書き換えない。

## 保存と検証

- 既存形式を優先する。新規の固定サイズ形式では、行順のセル配列と空セルの表現を決める。読み込み時に寸法、配列の形状、セット参照、タイル ID を検証する。
- 配置、速いドラッグ、消去、選択範囲をまたぐ操作、塗りつぶし、Undo / Redo を確認する。保存したマップを開き直し、寸法、レイヤー、セット参照、全セルが一致することを確認する。
- ミニマップの左右端への移動とズーム後の配置を試し、可視範囲の矩形、プレビュー、実際の配置位置が一致することを確認する。
