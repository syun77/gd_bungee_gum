# タイルマップエディタ作成の指針

ファイル操作や Undo / Redo の共通方針は [ツール作成.md](./ツール作成.md) に従う。

## 最小構成

- 幅・高さを持つ矩形グリッドを表示する。座標は左上を原点とし、右に列、下に行が増える。既存形式で座標規約が決まっている場合はそれに従う。
- タイル一覧から種類を選択できるようにし、選択中のタイルとカーソル位置のセル座標を表示する。空セルは配置済みのタイルと区別する。
- 左クリックで配置し、左ドラッグで通過セルに連続配置する。右クリックで消去する。グリッド外の操作ではデータを変更しない。
- 画面座標からセル座標への変換を一箇所にまとめる。1 回のドラッグは 1 回の Undo で戻せるようにする。

## 保存と確認

- 既存のマップ形式を優先する。新規形式なら、幅・高さと行順のセル配列を保存し、空セルの表現を決める。読み込み時は寸法、配列の形状、タイル ID を検証する。
- 配置、連続配置、消去、Undo / Redo、範囲外の操作を確認する。保存したマップを開き直し、寸法と全セルが一致することを確認する。
