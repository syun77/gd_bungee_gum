# ツール作成の指針

このリポジトリの補助ツールでは共通方針を適用し、実装する機能に応じて各節を参照する。

## 共通方針

- 利用者、実行環境、入出力、既存データへの影響を確認する。既存の操作や形式を優先し、要求範囲外の機能や依存関係を増やさない。
- 手動編集には GUI、反復実行や自動化には CLI を検討する。入力検証、処理、入出力の責務を分け、起動方法と入出力先を明示する。
- 連携先の形式を優先する。制約のない新規の構造化テキストには UTF-8 の JSON を候補とする。
- 必須項目、型、値の範囲を検証する。失敗時は原因を伝え、既存データを保持する。通常ファイルの上書きでは同じディレクトリに一時ファイルを書き終えてから置き換える。
- 通常の起動経路で動作を確認し、機能に応じて空データ、不正入力、境界値、読み書き失敗を試す。

## CLI・バッチ処理

- ヘルプで引数、既定値、入出力先を示す。標準出力には結果、標準エラー出力には診断を出し、失敗時は非ゼロの終了コードを返す。
- 複数ファイルを更新する場合は、上書き条件と途中失敗時の反映範囲を明示し、再実行時の動作を確認する。変更対象が多い場合はドライランを検討する。

## 対話型エディタ

- 小規模なデスクトップエディタには Python + Tkinter を候補とし、単一ファイルで見通せる範囲なら責務ごとに整理する。日本語入力が重要なら対象環境で IME の変換・確定を検証し、必要に応じて Windows では C# / WPF、macOS では SwiftUI または AppKit を検討する。

### ファイルを編集する場合

- Cmd+S で保存する。既存ファイルを開いている場合は上書き保存する。
- Cmd+O でファイル選択ダイアログを開く。
- 作業再開を備える場合は、最後に開いたファイルが存在すれば復元する。
- 最後に開いたファイルの情報は、ツール本体のデータと混同しない設定ファイルへ保存する。
- 保存前に必要な形式・必須項目・値の範囲を検証する。
- 開く・保存・JSON解析に失敗した場合は、データを壊さず、原因をダイアログで知らせる。

### Undo / Redo を備える場合

- Cmd+Z は UNDO、Cmd+Shift+Z は REDO とする。
- 編集操作単位で履歴を記録し、ドラッグ配置は一連の操作として扱う。
- 新しい編集を行ったら REDO 履歴を破棄する。
- 別のデータを開くか新規作成したときは履歴をリセットする。保存時は履歴を保持し、未保存状態の判定基準を更新する。
- Undo/Redo 後は表示、選択状態、未保存状態を同期する。
- 履歴には必要なデータだけを保持し、無制限に増やさない。

### 操作と表示

- 新規作成、開く、保存、名前を付けて保存、終了をメニューから実行できる。
- 未保存の変更がある場合、開く・新規作成・終了の前に保存確認を表示する。
- 編集中のファイル名と未保存状態をタイトルバーまたはステータスに表示する。
- 必要に応じて拡大・縮小や表示更新を用意する。
- キーボード操作だけでも主要機能へ到達できるよう、メニューにショートカットを表示する。
- macOS の Cmd を基本表記とし、Windows/Linux では同等の Ctrl 操作も可能にする。
- ウィンドウサイズや最後の表示設定を、必要な場合だけ設定として復元する。
- ダイアログ内の編集は入力時点で一時データへ保持し、親画面への反映は OK で行う。原則として Apply ボタンは作らない。

### 実装・検証

- データモデルと描画を分離し、描画処理から保存データを直接書き換えない。
- 同じ座標変換、検証、履歴登録を複数箇所へ複製しない。
- ファイルを開いた直後、編集直後、Undo/Redo 後、保存後に未保存状態が正しく更新されることを確認する。
- 空データ、不正 JSON、欠損項目、範囲外の値、存在しないファイルを確認する。
- 例外を握りつぶさず、利用者向けのエラーと開発者向けのログを必要に応じて分ける。

## グリッド編集を行う場合

- グリッド上にタイルを配置する場合、マウス操作が中心なら左クリックで配置する。
- 左ボタンを押したままドラッグすると、通過したセルへ連続して配置する。
- 右クリック、または指定された消去操作でタイルを消去できるようにする。
- グリッド座標とキャンバス座標の変換を一箇所に集約する。
- 範囲外のセル、不正な値、固定セルなど編集できない領域を明確に扱う。
- 現在のセル、選択中のタイル、操作結果を表示する。必要に応じて拡大・縮小やグリッド表示切り替えを用意する。
- 配置、連続配置、消去、編集不可領域をまたぐ操作を確認する。
